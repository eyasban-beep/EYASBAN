# 게임 기획서 (GDD) v0.3 — 가칭 「리아의 마법 옷장」

> 장르: 방치형(Idle) 뽑기 RPG (옷장 미믹 테마) · 플랫폼: Android 우선 → iOS
> 레퍼런스 구조: "열쇠로 장비를 뽑고 → 장착 → 자동전투 스테이지 진행" 계열 방치형 RPG
> 차별점: **판타지 세계관 + 미소녀 주인공 + 장비/코스튬이 그대로 보이는 아바타 꾸미기**

---

## 0. 원칙 (레퍼런스와의 관계)

- **게임 구조·시스템(루프, 슬롯 수, 던전/클랜전 형식 등)은 장르 공통 문법이므로 참고 가능.**
- **이름, 아트, UI 레이아웃 그대로 복제, 텍스트, 사운드, 데이터 테이블(수치표)은 가져오지 않는다.** 수치는 이 문서의 공식으로 직접 만든다.
- 앱 이름/아이콘/스토어 설명에 레퍼런스 게임명을 쓰지 않는다 (스토어 정책 위반·신고 대상).

## 1. 핵심 게임 루프

```
[열쇠 획득] → [클로제에게 열쇠 먹이기 = 장비 1개 뱉어냄(랜덤)]
      ↓
[장착 or 판매(골드)] → 전투력 상승 → 캐릭터 외형 변화(아바타)
      ↓
[자동전투 스테이지 진행] → 골드·열쇠·경험치·재료 드랍
      ↓
[골드로 클로제 레벨업] → 더 높은 티어 장비 확률 상승
      ↓
[던전/스킬/사역마/탈것/연구/클랜] 로 세로 성장 → 다음 챕터
```

- 세션 1회 목표: 3~5분 접속으로 "열쇠 몰아 쓰기 → 전투력 상승 → 보스 1회 도전"
- 오프라인 보상: 최대 12시간 (VIP/패스로 24시간)

## 2. 세계관 & 캐릭터

### 2.1 세계관
"마왕 벨제리아가 깨어나 대륙의 정령석을 집어삼킨다. 변방 마을 소녀 **리아**는
돌아가신 할머니의 낡은 옷장을 물려받는다. 그런데 그 옷장은 사실 살아 있는 미믹 **클로제**였다!
열쇠를 먹으면 옷과 무기를 뱉어내는 클로제와 함께, 리아는 마왕성으로 향한다."

### 2.2 주인공 (플레이어 아바타)
| 항목 | 내용 |
|---|---|
| 이름 | 리아 (변경 가능 닉네임) |
| 컨셉 | 패션을 좋아하는 시골 소녀, 밝고 고집 셈 |
| 전투 방식 | 장착 무기 타입에 따라 근접/원거리 자동 결정 |
| 외형 | 장착 장비 8부위가 그대로 보임 + 코스튬으로 덮어쓰기 가능 |

### 2.3 동료 히로인 (스킬/동료 가챠용, 런칭 12명 목표)
속성 5종: 불 / 물 / 바람 / 땅 / 빛·어둠

| 이름(가칭) | 속성 | 역할 | 컨셉 |
|---|---|---|---|
| 세라 | 불 | 딜러 | 화염 마법사, 츤데레 |
| 마린 | 물 | 힐러 | 인어 혼혈 성직자 |
| 실피 | 바람 | 딜러 | 엘프 궁수 |
| 노아 | 땅 | 탱커 | 드워프 방패병 |
| 루나 | 어둠 | 디버퍼 | 서큐버스 탈주자 (마왕군 출신) |
| 아이리스 | 빛 | 서포터 | 성기사 견습생 |
| ... | | | 시즌마다 2명씩 추가 |

> 동료 = 레퍼런스의 "스킬" 슬롯 역할을 대체. 동료를 편성하면 그 동료의 액티브 스킬이 자동 시전된다.

## 3. 장비 (옷장 미믹) 시스템

### 3.0 클로제 (옷장 미믹, 마스코트)
- 메인 화면 하단에 항상 등장. 열쇠를 먹이면 우물우물 → 장비를 퉤! 뱉음 (등급별 리액션 다름: 고티어일수록 눈이 반짝, 신화 등급은 춤)
- **클로제 레벨 = 성장 축**: 레벨이 오를수록 고티어 확률 상승 + 외형 진화
  - Lv1~9 낡은 나무 장롱 → Lv10 철장식 옷장 → Lv20 요정의 옷장 → Lv30 왕궁 드레스룸 → Lv40 용의 보물고 → Lv50 여신의 드레스룸
- 클로제 스킨(외형)도 별도 수집 가능 (BM)
- 대사/표정: 배고픔(열쇠 많을 때 재촉), 배부름(자동 먹이기 중), 삐침(오래 미접속)

### 3.1 장비 슬롯 — 8부위 (아바타 부위와 1:1 매핑)
| 슬롯 | 주 스탯 | 아바타 레이어 |
|---|---|---|
| 무기 | 공격력 | weapon |
| 투구/머리장식 | 체력 | head_acc |
| 갑옷/상의 | 체력 | top |
| 하의/치마 | 체력 | bottom |
| 장갑 | 공격력 | hand |
| 신발 | 체력 | shoes |
| 목걸이 | 공격력 | neck |
| 망토/날개 | 공격력 | back |

> 반지 대신 **망토/날개**를 넣어 "보이는 장비" 비율을 높인다 (아바타 BM 핵심).

### 3.2 재료 티어 (10단계) — 레퍼런스의 "시대(Age)" 개념 대체
| 티어 | 이름 | 색상 | 외형 테마 |
|---|---|---|---|
| T1 | 나무·가죽 | 회색 | 견습생 |
| T2 | 청동 | 초록 | 마을 경비대 |
| T3 | 철 | 파랑 | 모험가 |
| T4 | 강철 | 보라 | 기사단 |
| T5 | 미스릴 | 주황 | 엘프 공방 |
| T6 | 오리하르콘 | 빨강 | 드워프 왕실 |
| T7 | 정령석 | 하늘 | 정령 계약자 |
| T8 | 용린 | 금색 | 드래곤 슬레이어 |
| T9 | 성휘 | 흰빛 | 성녀 |
| T10 | 신화 | 무지개 | 별빛 여신 |

각 티어 × 8부위 × 디자인 3~5종 → 런칭 약 300종 장비 외형.

### 3.3 아이템 레벨 & 스탯
- 획득 시 아이템 레벨 = `클로제레벨 기반 범위 내 랜덤` (예: 클로제 Lv20 → 아이템 Lv 18~22)
- 주 스탯: `Base(slot) × TierMult(tier) × (1 + 0.08 × itemLv)`
  - TierMult: T1=1, 이후 ×1.9씩 (T10 ≈ 322)
- 부가 옵션(서브스탯): T3부터 1줄, T5 2줄, T8 3줄
  - 치명타 확률, 치명 피해, 공격속도, 흡혈, 피해감소, 스킬 쿨감, 골드 획득량, 보스 피해
  - **연속 공격 확률**(1회 공격 시 추가 타격), **근접 피해 % / 원거리 피해 %** (무기 타입별 빌드 분화)
- **비교 UI**: 획득 즉시 "현재 장착 vs 신규" 팝업 → 장착 / 판매 / 자동판매 설정

### 3.4 클로제 레벨 & 티어 확률 (예시 — 직접 밸런싱)
| 클로제 Lv | T1 | T2 | T3 | T4 | T5 | T6 | T7+ |
|---|---|---|---|---|---|---|---|
| 1 | 100% | | | | | | |
| 5 | 70 | 30 | | | | | |
| 10 | 40 | 45 | 15 | | | | |
| 20 | 10 | 35 | 40 | 15 | | | |
| 30 | | 15 | 40 | 35 | 10 | | |
| 40 | | | 20 | 40 | 32 | 8 | |
| 50+ | 테이블을 한 칸씩 우측 시프트 | | | | | | |

- 클로제 레벨업: 골드 + 시간(업그레이드 대기), 대기 시간은 보석/광고로 단축
- 자동 먹이기: 클로제 Lv10 해금, "티어 X 미만 자동판매" 필터

### 3.5 열쇠
- 획득처: 스테이지 드랍, 오프라인 보상, 열쇠 던전, 퀘스트, 광고, 상점
- 다중 먹이기: x1 / x5 / x10 (연출 스킵)

## 4. 아바타 꾸미기 시스템 (핵심 차별화)

### 4.1 레이어 구조 (Spine 2D 스킨/어태치먼트 기반)
```
[뒤] aura → back(망토/날개) → hair_back → body → bottom → top → neck
     → hand → weapon → face(눈/입/표정) → hair_front → head_acc → effect [앞]
```
- 장비를 끼면 해당 부위 외형이 자동 교체
- **코스튬(외형 전용)** 을 끼면 장비 외형을 덮어씀 (스탯은 장비 기준)
- 헤어·눈·피부톤·표정은 커스터마이즈 (무료 기본 + 유료 추가)

### 4.2 코스튬 획득 & 가치
| 분류 | 획득처 | 효과 |
|---|---|---|
| 장비 외형 도감 | 한 번 획득한 장비 외형은 도감 등록 → 언제든 외형으로 사용 | 도감 수집 보너스(공/체 %) |
| 코스튬 세트 | 코스튬 뽑기, 시즌 패스, 이벤트 | 세트 보유 효과(소량 스탯) |
| 한정 코스튬 | 클랜전 시즌 보상, 랭킹 | 칭호 + 오라 이펙트 |

- **"외형은 스탯과 분리"** 를 원칙으로 → 과금 외형이 P2W 비판을 덜 받음 (보유 효과만 소량)
- 포토 모드: 배경(챕터 배경 12종)·포즈·표정 선택 후 스크린샷 공유

### 4.3 동료 히로인 꾸미기
- 동료도 코스튬 3종(기본/이벤트/한정) — 로비에서 리아 옆에 최대 2명 세워두기

## 5. 전투

- 횡스크롤 자동전투, 리아 + 사역마 1 + (동료 스킬 이펙트)
- 스탯: 공격력, 체력, 공격속도, 치명타율/피해, 흡혈, 피해감소, 이동속도(탈것)
- 데미지 공식: `dmg = ATK × skillCoef × (crit ? critDmg : 1) × elemMult × (1 - targetDR)`
- 속성 상성: 불>바람>땅>물>불 (1.3배), 빛↔어둠 상호 1.3배
- 보스전: 제한시간 60초, 실패 시 직전 스테이지 무한 파밍(레퍼런스 계열 공통)

## 6. 스테이지 — 12 챕터 (마을 → 마왕성)

각 챕터 = **10 스테이지** (X-1 ~ X-10), 각 스테이지 5웨이브, **X-10은 챕터 보스**.
12챕터 클리어 후 **난이도 반복**: 노멀 → 하드 → 지옥 → 심연(무한) — 몬스터 스탯 배율 상승, 고티어 재료 드랍.

| Ch | 지역 | 테마/분위기 | 일반 몬스터 | 챕터 보스 | 해금 콘텐츠 |
|---|---|---|---|---|---|
| 1 | 시작의 마을 「아르테」 | 불탄 마을, 튜토리얼 | 슬라임, 들쥐, 고블린 정찰병 | 고블린 대장 「그룩」 | 자동 먹이기, 스킬(동료) |
| 2 | 바람의 초원 | 풍차, 들판 | 늑대, 멧돼지, 허수아비 | 거대 늑대 「펜릴 새끼」 | 사역마, 골드 던전 |
| 3 | 속삭이는 숲 | 거대수, 반딧불 | 버섯병사, 트렌트 묘목, 숲도깨비 | 고목 「엘더 트렌트」 | 연구(테크트리) |
| 4 | 요정의 깊은 숲 | 보랏빛 마력, 요정 | 타락 요정, 독나방, 덩굴 | 타락한 요정여왕 「티타니아」 | 열쇠 던전, 아레나 |
| 5 | 수정 동굴 | 빛나는 수정 | 박쥐, 수정 골렘, 코볼트 | 수정 거미 「아라크네아」 | 길드 |
| 6 | 드워프 폐광 | 용암, 레일, 폐광 | 광산 해골, 화염 정령, 두더지기사 | 광산 골렘왕 「바위심장」 | 탈것 |
| 7 | 황금 사막 | 모래 언덕, 태양 | 전갈, 모래 도적, 미라 | 사막 지렁이 「샌드웜」 | 사역마 던전 |
| 8 | 잊혀진 피라미드 | 유적, 함정 | 아누비스 병사, 스핑크스 석상 | 미라 여왕 「네페르」 | 길드전 |
| 9 | 은빛 대하 | 강, 다리, 수상마을 | 갓파, 강의 정령, 수룡 새끼 | 강의 수호룡 「실버린」 | 보스 레이드 던전 |
| 10 | 폭풍의 바다 | 해적선, 폭풍 | 해적 스켈레톤, 세이렌, 상어인간 | 크라켄 「심해의 군주」 | 코스튬 상점 확장 |
| 11 | 마계 해안 「검은 섬」 | 화산, 붉은 하늘 | 임프, 헬하운드, 마족 기사 | 마왕군 사천왕 「흑기사 발데르」 | 심연 탑(무한) |
| 12 | **마왕성 「판데모니움」** | 성 내부, 왕좌 | 가고일, 마녀, 데몬 나이트 | **최종 보스: 마왕 「벨제리아」** | 하드 난이도, 엔딩 |

### 6.1 최종 보스 — 마왕 벨제리아 (12-10)
- 3페이즈, 제한시간 90초 (12-10만 예외)
  1. **페이즈1 (HP 100~70%)**: 마검 휘두르기 + 소환수(가고일) 2마리
  2. **페이즈2 (70~30%)**: 속성 실드 — 실드 속성 상성 동료를 편성해야 효율적으로 파괴
  3. **페이즈3 (30~0%)**: 광폭화(공속+50%), 10초마다 "절망의 파동"(최대HP 30% 피해) → 흡혈/피해감소 빌드 요구
- 클리어 연출: 마왕이 사실은 봉인된 소녀였다는 반전 컷신 → **마왕 벨제리아를 동료(한정 히로인)로 획득** (하드 난이도 진입 동기)
- 각 챕터 보스도 하드 난이도에서 "패턴 1개 추가"

### 6.2 스테이지 밸런스 공식
- 몬스터 HP: `HP(s) = 50 × 1.13^s` (s = 누적 스테이지 번호 1~120)
- 몬스터 ATK: `ATK(s) = 8 × 1.12^s`
- 보스 배율: HP ×12, ATK ×3
- 난이도 배율: 하드 ×(1.13^120)부터 재시작 개념 → 실제로는 s를 120부터 이어서 계산
- 상세 표는 `docs/data/stages.csv`

## 7. 성장 시스템

### 7.1 스킬 = 동료 히로인 (가챠)
- 편성 슬롯 3개 (Ch1 1개 → Ch4 2개 → Ch8 3개)
- 등급 6단계(동료·사역마·탈것 공통): **일반 / 고급 / 희귀 / 영웅 / 전설 / 신화** (색: 회·하늘·초록·노랑·빨강·보라 → 아트 확정 시 재검토)
- 중복 획득 → 레벨업(조각), 5/10/20 레벨마다 각성(패시브 추가 + 일러스트 변화)
- 각 동료: 액티브 1 + 보유효과 패시브 1 (보유만 해도 스탯)

### 7.2 사역마 (펫 대체)
- 알(Egg) 획득 → 부화 시간 → 랜덤 사역마 (작은 용, 정령, 고양이 요정, 슬라임 등)
- 1마리 출전(전투 보조 공격) + 보유효과
- 등급 5단계, 합성(같은 등급 3 → 상위 1 확률)

### 7.3 탈것
- Ch6 해금. 이동속도(파밍 효율) + 보유효과
- 외형: 유니콘, 그리폰, 마법 빗자루, 거대 고양이 등 — 아바타와 함께 노출

### 7.4 연구 (테크트리) — 3 갈래
| 트리 | 노드 예시 |
|---|---|
| 옷장 | 먹이기 속도, 티어 확률 +, 다중 먹이기 해금, 자동판매 필터, 열쇠 최대 보유량 |
| 전투 | 공격력 %, 체력 %, 치명타, 보스 피해, 오프라인 보상 시간 |
| 마법 | 동료 스킬 쿨감, 사역마 공격력, 부화 시간 단축, 탈것 효과 |
- 노드 연구 = 골드 + 연구석 + 실시간 대기(동시 연구 1슬롯, 패스로 2슬롯)

### 7.5 계정 레벨 / 칭호 / 업적
- 퀘스트(일일/주간/메인)로 계정 경험치 → 레벨 보상
- 업적: 달성률(%) 표시, 보상은 보석 소량 + 칭호. 클랜 활동(임무, 클랜 유지 일수) 업적 포함

### 7.6 귀향 (환생/프레스티지)
- 조건: 하드 이상 난이도에서 특정 챕터 도달
- 실행 시: 스테이지 진행도 → 1챕터로 초기화 / **장비·동료·사역마·탈것·코스튬은 유지**
- 보상: 「추억의 별」 → 영구 버프 트리(골드 획득, 열쇠 드랍, 클로제 확률 등)
- 연출: 리아가 고향 마을로 돌아가 할머니 묘에 보고 → 다음 회차 마을 외형이 조금씩 재건됨 (회차 수 = 마을 복구도)
- 회차가 쌓일수록 귀향 조건 챕터가 뒤로 밀림

## 10. 클랜(길드) & 길드전

### 10.1 길드 기본
- 정원 50명, 길드 등급(길드 총 전력 기준): **원석 → 동 → 은 → 금 → 백금 → 다이아 → 별빛** (각 3단계)
- 가입 방식: 자유 / 승인제 / 비공개, 가입 요청 승인·거절, 공지사항, 길드 채팅 + 간부 채팅
- **직급** (명칭 자체 — 원작 R1~R5 명칭 미사용)
  | 직급 | 권한 |
  |---|---|
  | 길드장 | 전 권한, 부길드장까지 임명/해임 |
  | 부길드장 | 근위대장 이하 임명/해임, 공지, 가입 설정, 추방, 길드 연구 추천 |
  | 근위대장 | 정예 이하 임명/해임, 공지, 가입 승인, 길드 연구 추천 |
  | 정예 / 기사 / 견습 기사 / 신입 | 활동 기간·기여도에 따라 승급 (권한 없음, 표시용) |
- **길드 연구**: 길드원이 「마력 잉크」를 기부 → 길드 전체 영구 버프(%) — 랭킹에 연구 수치 표시
- 길드 상점: 열쇠, 알, 길드 전용 코스튬

### 10.2 길드 의뢰 + 응원 (원작 "임무/랠리" 구조 참고)
- 1인 **의뢰 행동력 3/일**, 매일 09:00 충전, **성공 시에만 소모**
- 의뢰마다 레벨·권장 전투력·보상(연구석, 소환권, 열쇠, 알)
- **응원**: 누군가 의뢰를 성공하면 길드원 전원에게 「응원 상자」(열쇠 소량)가 쌓임 → 우편처럼 일괄 수령
- 의뢰명은 자체 작성 (예: 「고블린 보급로 차단」, 「잃어버린 드레스 찾기」)

### 10.3 길드전 (주간 활동 점수 경쟁)
- 다른 서버의 비슷한 등급 길드와 1:1 매칭, **6일 진행 + 1일 정산**
- 매일 **테마별 점수 행동**이 다름. 길드원 전체 활동 점수 합으로 그날 승패 결정
  | 일차 | 테마 | 점수 행동 예시 | 일차 승리 포인트 |
  |---|---|---|---|
  | 1 | 옷장의 날 | 열쇠 먹이기, 클로제 레벨업 | 1 |
  | 2 | 연구의 날 | 연구 노드 완료(단계별 차등) | 2 |
  | 3 | 모험의 날 | 던전 입장권 사용, 심연의 탑 층 돌파 | 2 |
  | 4 | 소환의 날 | 동료·사역마·탈것 소환(등급별 차등) | 3 |
  | 5 | 성장의 날 | 동료 레벨업, 장비 획득 티어별 | 3 |
  | 6 | 총력전 | 1~5일차 모든 행동 (점수 ×1.5) | 5 |
  - 총 16점 → 마지막 날 역전 가능 (점수값은 데이터 테이블로 관리, 원작 수치 미사용)
- 일차별 승자 + **MVP**(그날 최고 기여자) 표시 → MVP 리아는 로비에 "오늘의 MVP" 코스튬 이펙트
- 보상: ① 승패 보상 ② **개인 누적 포인트 마일스톤 보상** ③ 길드 등급별 보상 배율. 진행 중 "예상 보상" 표시
- 설계 의도: 과금·접속 행동이 곧 길드 기여 → 길드 소속감 + 매출 연결. 단, 무과금도 의뢰·던전으로 기여 가능하게 점수 비중 조절

### 10.4 길드 보스 (해금: 길드 등급 은)
- 주간 공동 보스, 1인 일 3회, 누적 피해 단계별 보상

### 10.5 서버 권한
- 길드전 점수·가챠·의뢰 결과는 **반드시 서버 판정**. 전투는 결정론적 시뮬레이션(시드 고정) → 서버 재검증.

## 12. 가챠 & BM

### 12.1 동료 소환 (예시 확률 — 실제 공시 필요)
| 등급 | 확률 |
|---|---|
| 일반 | 60% |
| 희귀 | 28% |
| 영웅 | 9% |
| 전설 | 2.7% |

- 천장: 100회 내 전설 이상 1회 확정, 픽업 배너 200회 픽업 확정

### 12.1.1 소환 숙련도 (동료·사역마·탈것 각각 별도)
- 소환 횟수만큼 숙련도 경험치 → 숙련도 Lv1~50
- 숙련도가 오를수록 상위 등급 확률이 단계적으로 상승 (위 표는 Lv1 기준)
- 숙련도 Lv50 확률표 예시(자체 수치): 일반 10 / 고급 20 / 희귀 25 / 영웅 25 / 전설 15 / 신화 5
- 등급 내 개별 캐릭터 확률까지 공시 (법적 요구 + 신뢰)

### 12.2 상품
- **코스튬 뽑기/직판** (메인 BM — 미소녀 아바타)
- 시즌 패스(4주): 무료/유료 라인, 유료 라인 최종 보상 = 한정 코스튬 세트
- 월정액: 매일 보석 + 오프라인 24h + 광고 제거 일부
- 광고 제거 영구 상품
- 성장 패키지(챕터 클리어 단계별)
- **오늘의 특가**: 묶음 상품 3종(소환 묶음 / 성장 묶음 / 자원 묶음), 3개 모두 구매 시 다음 3종 등장 (일 1회 갱신)
- 보석 상품: 구글플레이 가격대 4~6단(₩1,200~₩149,000) — 보석 수량은 자체 설정
- 리워드 광고: 열쇠 2배, 입장권, 오프라인 보상 2배

### 12.3 법/정책 체크 (한국 출시 기준)
- 확률형 아이템 확률 표시 의무 (게임산업법, 2024.3 시행) — 게임 내·홈페이지·광고에 표기

# 게임 기획서 (GDD) v0.1 — 가칭 「별빛 대장간 (Starforge Maidens)」

> 장르: 방치형(Idle) 대장간 RPG · 플랫폼: Android 우선 → iOS
> 레퍼런스 구조: "망치로 장비를 뽑고 → 장착 → 자동전투 스테이지 진행" 계열 방치형 RPG
> 차별점: **판타지 세계관 + 미소녀 주인공 + 장비/코스튬이 그대로 보이는 아바타 꾸미기**

---

## 0. 원칙 (레퍼런스와의 관계)

- **게임 구조·시스템(루프, 슬롯 수, 던전/클랜전 형식 등)은 장르 공통 문법이므로 참고 가능.**
- **이름, 아트, UI 레이아웃 그대로 복제, 텍스트, 사운드, 데이터 테이블(수치표)은 가져오지 않는다.** 수치는 이 문서의 공식으로 직접 만든다.
- 앱 이름/아이콘/스토어 설명에 레퍼런스 게임명을 쓰지 않는다 (스토어 정책 위반·신고 대상).

---

## 1. 핵심 게임 루프

```
[망치 획득] → [대장간에서 망치 사용 = 장비 1개 단조(랜덤)]
      ↓
[장착 or 판매(골드)] → 전투력 상승 → 캐릭터 외형 변화(아바타)
      ↓
[자동전투 스테이지 진행] → 골드·망치·경험치·재료 드랍
      ↓
[골드로 대장간 레벨업] → 더 높은 티어 장비 확률 상승
      ↓
[던전/스킬/사역마/탈것/연구/클랜] 로 세로 성장 → 다음 챕터
```

- 세션 1회 목표: 3~5분 접속으로 "망치 몰아 쓰기 → 전투력 상승 → 보스 1회 도전"
- 오프라인 보상: 최대 12시간 (VIP/패스로 24시간)

## 2. 세계관 & 캐릭터

### 2.1 세계관
"마왕 벨제리아가 깨어나 대륙의 정령석을 집어삼킨다. 변방 마을의 견습 대장장이 소녀 **리아**는
전설의 '별빛 모루'를 물려받아, 스스로 벼린 장비를 두르고 마왕성으로 향한다."

### 2.2 주인공 (플레이어 아바타)
| 항목 | 내용 |
|---|---|
| 이름 | 리아 (변경 가능 닉네임) |
| 컨셉 | 견습 대장장이 소녀, 밝고 고집 셈 |
| 전투 방식 | 장착 무기 타입에 따라 근접/원거리 자동 결정 |
| 외형 | 장착 장비 8부위가 그대로 보임 + 코스튬으로 덮어쓰기 가능 |

### 2.3 동료 히로인 (스킬/동료 가챠용, 런칭 12명 목표)
속성 5종: 불 / 물 / 바람 / 땅 / 빛·어둠

| 이름(가칭) | 속성 | 역할 | 컨셉 |
|---|---|---|---|
| 세라 | 불 | 딜러 | 화염 마법사, 츤데레 |
| 마린 | 물 | 힐러 | 인어 혼혈 성직자 |
| 실피 | 바람 | 딜러 | 엘프 궁수 |
| 노아 | 땅 | 탱커 | 드워프 방패병 |
| 루나 | 어둠 | 디버퍼 | 서큐버스 탈주자 (마왕군 출신) |
| 아이리스 | 빛 | 서포터 | 성기사 견습생 |
| ... | | | 시즌마다 2명씩 추가 |

> 동료 = 레퍼런스의 "스킬" 슬롯 역할을 대체. 동료를 편성하면 그 동료의 액티브 스킬이 자동 시전된다.

## 3. 장비 (대장간) 시스템

### 3.1 장비 슬롯 — 8부위 (아바타 부위와 1:1 매핑)
| 슬롯 | 주 스탯 | 아바타 레이어 |
|---|---|---|
| 무기 | 공격력 | weapon |
| 투구/머리장식 | 체력 | head_acc |
| 갑옷/상의 | 체력 | top |
| 하의/치마 | 체력 | bottom |
| 장갑 | 공격력 | hand |
| 신발 | 체력 | shoes |
| 목걸이 | 공격력 | neck |
| 망토/날개 | 공격력 | back |

> 반지 대신 **망토/날개**를 넣어 "보이는 장비" 비율을 높인다 (아바타 BM 핵심).

### 3.2 재료 티어 (10단계) — 레퍼런스의 "시대(Age)" 개념 대체
| 티어 | 이름 | 색상 | 외형 테마 |
|---|---|---|---|
| T1 | 나무·가죽 | 회색 | 견습생 |
| T2 | 청동 | 초록 | 마을 경비대 |
| T3 | 철 | 파랑 | 모험가 |
| T4 | 강철 | 보라 | 기사단 |
| T5 | 미스릴 | 주황 | 엘프 공방 |
| T6 | 오리하르콘 | 빨강 | 드워프 왕실 |
| T7 | 정령석 | 하늘 | 정령 계약자 |
| T8 | 용린 | 금색 | 드래곤 슬레이어 |
| T9 | 성휘 | 흰빛 | 성녀 |
| T10 | 신화 | 무지개 | 별빛 여신 |

각 티어 × 8부위 × 디자인 3~5종 → 런칭 약 300종 장비 외형.

### 3.3 아이템 레벨 & 스탯
- 단조 시 아이템 레벨 = `대장간레벨 기반 범위 내 랜덤` (예: 대장간 Lv20 → 아이템 Lv 18~22)
- 주 스탯: `Base(slot) × TierMult(tier) × (1 + 0.08 × itemLv)`
  - TierMult: T1=1, 이후 ×1.9씩 (T10 ≈ 322)
- 부가 옵션(서브스탯): T3부터 1줄, T5 2줄, T8 3줄
  - 치명타 확률, 치명 피해, 공격속도, 흡혈, 피해감소, 스킬 쿨감, 골드 획득량, 보스 피해
- **비교 UI**: 단조 즉시 "현재 장착 vs 신규" 팝업 → 장착 / 판매 / 자동판매 설정

### 3.4 대장간 레벨 & 티어 확률 (예시 — 직접 밸런싱)
| 대장간 Lv | T1 | T2 | T3 | T4 | T5 | T6 | T7+ |
|---|---|---|---|---|---|---|---|
| 1 | 100% | | | | | | |
| 5 | 70 | 30 | | | | | |
| 10 | 40 | 45 | 15 | | | | |
| 20 | 10 | 35 | 40 | 15 | | | |
| 30 | | 15 | 40 | 35 | 10 | | |
| 40 | | | 20 | 40 | 32 | 8 | |
| 50+ | 테이블을 한 칸씩 우측 시프트 | | | | | | |

- 대장간 레벨업: 골드 + 시간(업그레이드 대기), 대기 시간은 보석/광고로 단축
- 자동 단조: 대장간 Lv10 해금, "티어 X 미만 자동판매" 필터

### 3.5 망치
- 획득처: 스테이지 드랍, 오프라인 보상, 망치 던전, 퀘스트, 광고, 상점
- 다중 단조: x1 / x5 / x10 (연출 스킵)

## 4. 아바타 꾸미기 시스템 (핵심 차별화)

### 4.1 레이어 구조 (Spine 2D 스킨/어태치먼트 기반)
```
[뒤] aura → back(망토/날개) → hair_back → body → bottom → top → neck
     → hand → weapon → face(눈/입/표정) → hair_front → head_acc → effect [앞]
```
- 장비를 끼면 해당 부위 외형이 자동 교체
- **코스튬(외형 전용)** 을 끼면 장비 외형을 덮어씀 (스탯은 장비 기준)
- 헤어·눈·피부톤·표정은 커스터마이즈 (무료 기본 + 유료 추가)

### 4.2 코스튬 획득 & 가치
| 분류 | 획득처 | 효과 |
|---|---|---|
| 장비 외형 도감 | 한 번 단조한 장비 외형은 도감 등록 → 언제든 외형으로 사용 | 도감 수집 보너스(공/체 %) |
| 코스튬 세트 | 코스튬 뽑기, 시즌 패스, 이벤트 | 세트 보유 효과(소량 스탯) |
| 한정 코스튬 | 클랜전 시즌 보상, 랭킹 | 칭호 + 오라 이펙트 |

- **"외형은 스탯과 분리"** 를 원칙으로 → 과금 외형이 P2W 비판을 덜 받음 (보유 효과만 소량)
- 포토 모드: 배경(챕터 배경 12종)·포즈·표정 선택 후 스크린샷 공유

### 4.3 동료 히로인 꾸미기
- 동료도 코스튬 3종(기본/이벤트/한정) — 로비에서 리아 옆에 최대 2명 세워두기

## 5. 전투

- 횡스크롤 자동전투, 리아 + 사역마 1 + (동료 스킬 이펙트)
- 스탯: 공격력, 체력, 공격속도, 치명타율/피해, 흡혈, 피해감소, 이동속도(탈것)
- 데미지 공식: `dmg = ATK × skillCoef × (crit ? critDmg : 1) × elemMult × (1 - targetDR)`
- 속성 상성: 불>바람>땅>물>불 (1.3배), 빛↔어둠 상호 1.3배
- 보스전: 제한시간 60초, 실패 시 직전 스테이지 무한 파밍(레퍼런스 계열 공통)

## 6. 스테이지 — 12 챕터 (마을 → 마왕성)

각 챕터 = **10 스테이지** (X-1 ~ X-10), 각 스테이지 5웨이브, **X-10은 챕터 보스**.
12챕터 클리어 후 **난이도 반복**: 노멀 → 하드 → 지옥 → 심연(무한) — 몬스터 스탯 배율 상승, 고티어 재료 드랍.

| Ch | 지역 | 테마/분위기 | 일반 몬스터 | 챕터 보스 | 해금 콘텐츠 |
|---|---|---|---|---|---|
| 1 | 시작의 마을 「아르테」 | 불탄 마을, 튜토리얼 | 슬라임, 들쥐, 고블린 정찰병 | 고블린 대장 「그룩」 | 자동단조, 스킬(동료) |
| 2 | 바람의 초원 | 풍차, 들판 | 늑대, 멧돼지, 허수아비 | 거대 늑대 「펜릴 새끼」 | 사역마, 골드 던전 |
| 3 | 속삭이는 숲 | 거대수, 반딧불 | 버섯병사, 트렌트 묘목, 숲도깨비 | 고목 「엘더 트렌트」 | 연구(테크트리) |
| 4 | 요정의 깊은 숲 | 보랏빛 마력, 요정 | 타락 요정, 독나방, 덩굴 | 타락한 요정여왕 「티타니아」 | 망치 던전, 아레나 |
| 5 | 수정 동굴 | 빛나는 수정 | 박쥐, 수정 골렘, 코볼트 | 수정 거미 「아라크네아」 | 클랜 |
| 6 | 드워프 폐광 | 용암, 레일, 폐광 | 광산 해골, 화염 정령, 두더지기사 | 광산 골렘왕 「바위심장」 | 탈것 |
| 7 | 황금 사막 | 모래 언덕, 태양 | 전갈, 모래 도적, 미라 | 사막 지렁이 「샌드웜」 | 사역마 던전 |
| 8 | 잊혀진 피라미드 | 유적, 함정 | 아누비스 병사, 스핑크스 석상 | 미라 여왕 「네페르」 | 클랜전 |
| 9 | 은빛 대하 | 강, 다리, 수상마을 | 갓파, 강의 정령, 수룡 새끼 | 강의 수호룡 「실버린」 | 보스 레이드 던전 |
| 10 | 폭풍의 바다 | 해적선, 폭풍 | 해적 스켈레톤, 세이렌, 상어인간 | 크라켄 「심해의 군주」 | 코스튬 상점 확장 |
| 11 | 마계 해안 「검은 섬」 | 화산, 붉은 하늘 | 임프, 헬하운드, 마족 기사 | 마왕군 사천왕 「흑기사 발데르」 | 심연 탑(무한) |
| 12 | **마왕성 「판데모니움」** | 성 내부, 왕좌 | 가고일, 마녀, 데몬 나이트 | **최종 보스: 마왕 「벨제리아」** | 하드 난이도, 엔딩 |

### 6.1 최종 보스 — 마왕 벨제리아 (12-10)
- 3페이즈, 제한시간 90초 (12-10만 예외)
  1. **페이즈1 (HP 100~70%)**: 마검 휘두르기 + 소환수(가고일) 2마리
  2. **페이즈2 (70~30%)**: 속성 실드 — 실드 속성 상성 동료를 편성해야 효율적으로 파괴
  3. **페이즈3 (30~0%)**: 광폭화(공속+50%), 10초마다 "절망의 파동"(최대HP 30% 피해) → 흡혈/피해감소 빌드 요구
- 클리어 연출: 마왕이 사실은 봉인된 소녀였다는 반전 컷신 → **마왕 벨제리아를 동료(한정 히로인)로 획득** (하드 난이도 진입 동기)
- 각 챕터 보스도 하드 난이도에서 "패턴 1개 추가"

### 6.2 스테이지 밸런스 공식
- 몬스터 HP: `HP(s) = 50 × 1.13^s` (s = 누적 스테이지 번호 1~120)
- 몬스터 ATK: `ATK(s) = 8 × 1.12^s`
- 보스 배율: HP ×12, ATK ×3
- 난이도 배율: 하드 ×(1.13^120)부터 재시작 개념 → 실제로는 s를 120부터 이어서 계산
- 상세 표는 `docs/data/stages.csv`

## 7. 성장 시스템

### 7.1 스킬 = 동료 히로인 (가챠)
- 편성 슬롯 3개 (Ch1 1개 → Ch4 2개 → Ch8 3개)
- 등급: 일반 / 희귀 / 영웅 / 전설 / 신화
- 중복 획득 → 레벨업(조각), 5/10/20 레벨마다 각성(패시브 추가 + 일러스트 변화)
- 각 동료: 액티브 1 + 보유효과 패시브 1 (보유만 해도 스탯)

### 7.2 사역마 (펫 대체)
- 알(Egg) 획득 → 부화 시간 → 랜덤 사역마 (작은 용, 정령, 고양이 요정, 슬라임 등)
- 1마리 출전(전투 보조 공격) + 보유효과
- 등급 5단계, 합성(같은 등급 3 → 상위 1 확률)

### 7.3 탈것
- Ch6 해금. 이동속도(파밍 효율) + 보유효과
- 외형: 유니콘, 그리폰, 마법 빗자루, 거대 고양이 등 — 아바타와 함께 노출

### 7.4 연구 (테크트리) — 3 갈래
| 트리 | 노드 예시 |
|---|---|
| 대장간 | 단조 속도, 티어 확률 +, 다중단조 해금, 자동판매 필터, 망치 최대 보유량 |
| 전투 | 공격력 %, 체력 %, 치명타, 보스 피해, 오프라인 보상 시간 |
| 마법 | 동료 스킬 쿨감, 사역마 공격력, 부화 시간 단축, 탈것 효과 |
- 노드 연구 = 골드 + 연구석 + 실시간 대기(동시 연구 1슬롯, 패스로 2슬롯)

### 7.5 계정 레벨 / 칭호 / 업적
- 퀘스트(일일/주간/메인)로 계정 경험치 → 레벨 보상

## 10. 클랜 & 클랜전

### 10.1 클랜 기본
- 인원 30명, 클랜 레벨(기부 경험치) → 인원/버프 확장
- 일일 기부(골드/보석) → 클랜 코인
- **클랜 보스**: 주간 공동 보스, 1인 일 3회, 누적 피해 단계별 보상
- 클랜 상점: 망치, 알, 클랜 전용 코스튬

### 10.2 클랜전 (주간)
| 요일 | 단계 |
|---|---|
| 월 | 신청 & 매칭 (클랜 전투력 기준) |
| 화~수 | 준비: 방어 편성 확정 |
| 목~토 | 공격: 1인 일 3회, 상대 클랜원 방어덱 공격 → 별(★0~3) 획득 |
| 일 | 정산: 별 합계 승패, 클랜전 리그 포인트 |
- 별 기준: 승리 ★1, 제한시간 50% 이내 ★2, 체력 70% 이상 남기고 ★3
- 같은 대상에게 더 높은 별을 얻은 경우만 갱신
- 시즌(4주) 리그 보상: 한정 오라/칭호/코스튬

### 10.3 서버 권한
- 클랜전/아레나/가챠는 **반드시 서버 판정** (클라 결과 신뢰 X). 전투는 결정론적 시뮬레이션(시드 고정) → 서버 재검증.

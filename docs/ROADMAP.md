# 개발 로드맵 v0.2 — 1인 · 개발 첫 경험 · 글로벌 출시 기준

> ⚠️ 현실 점검: 1인·첫 개발로 "기획서 전체 + 글로벌 출시"를 내년 초(2~3개월)에 하는 것은 불가능에 가깝다.
> 같은 장르 소규모 팀도 보통 8~12개월. 아래는 **내년 초 = 플레이 가능한 테스트 빌드**, **정식 출시 = 내년 하반기** 목표.
> 코드는 Claude가 작성하고, 사용자는 Unity에서 실행·확인·아트 교체를 맡는 분업을 전제로 한다.

## M0. 준비 (1~2주) — 2026.11
- [ ] Unity 6 LTS 설치, 이 저장소에 Unity 프로젝트(`Game/`) 생성, Git LFS 설정
- [ ] Unity 기초: 씬 열기, Play 버튼, 인스펙터에서 값 바꾸기, 안드로이드 빌드 1회 (튜토리얼 반나절)
- [ ] 아트 파이프라인 테스트: AI 시안 → Krita로 정리 → SD 리아 몸 + 상의 2종 겹쳐보기
- [ ] 수위·배포처 결정 (GDD 12.3) ← **아트 방향이 여기서 갈림**

## M1. 코어 루프 (4~6주) — 2026.12 ~ 2027.01
- [ ] 클로제 먹이기: 열쇠 → 랜덤 장비 → 비교 팝업 → 장착/판매
- [ ] 클로제 레벨업 + 티어 확률
- [ ] 자동전투 + 챕터 1~3 (임시 아트)
- [ ] 아바타: 8부위 Sprite Swap
- [ ] 오프라인 보상, 로컬 세이브
- **완료 기준: 지인 5명이 30분 플레이 후 "또 하고 싶다"**

## M2. 성장 시스템 (6~8주) — 2027.02 ~ 03

- [ ] 던전 4종 (보물창고/서고/둥지/약초원) + 소탕
- [ ] 챕터 1~12 + 보스, 최종보스 3페이즈
- [ ] 코스튬·도감·포토 모드
- **→ 2027 초: 구글플레이 비공개 테스트 (오프라인 싱글 버전)**

## M3. 온라인 (8~10주) — 2027.04 ~ 06

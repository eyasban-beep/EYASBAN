# 레퍼런스 분석 #02 — 스크린샷 16장 (던전·승천·기술 트리·테크 레이스·메인 화면·요정·진행 패스)

> 관찰 기록. 원작 명칭·수치는 우리 게임에 그대로 쓰지 않는다.

## 1. 관찰 내용

### 1.1 던전 (4종)
- 던전마다 **전용 열쇠(색 구분)**, 각 2개/일, 매일 09:00 충전, **클리어했을 때만 소모**
- 난이도 = "단계-하위단계"(예: 38-4) 형태로 계속 올라가는 구조
- 버튼 2개: **이전 스테이지 소탕**(즉시 보상) / **입장**(다음 단계 도전)
- **던전 1개 = 성장 재화 1개** 공급: 망치(+코인) / 스킬 티켓 / 펫 알 / 물약(기술 트리 재화)

### 1.2 승천 (⚠️ 이전 분석 수정)
- 승천은 **계정 환생이 아니라 시스템별(펫 등) 리셋**
- 소환 레벨 최대(100) 도달 → 승천 시 **해당 시스템의 보유 펫·알 전부 제거 + 소환 레벨 1로 초기화**, 대신 이후 나오는 펫이 더 강해짐
- 기술 트리 화면에 "어센션 보너스" 별도 표시

### 1.3 기술 트리 (시즌제, 클랜 연동)
- 재화: 물약. 상단에 클랜명 + 클랜 기술 %, MVP 표시
- **약 2개월 시즌 종료 시 기술 트리와 물약 초기화**
- 카테고리: 전투력(장비 부위별 8 + 스킬/펫/탈것 피해·체력) / 알 타이머(알 종류별) / 특수(망치 추가, 대장간 속도, 이동, 기타) / **클랜 전쟁(1~6일차별 점수 부스트, 전쟁 전투 버프)** / 클랜 미션 / **던전별 피해·체력** / 클랜 기술 물약 획득량
- 노드 최대 단계가 노드마다 다름 (2, 3, 10, 20, 60, 100 등)
- 추천 노드 표시(👍) — 간부가 "클랜 기술 추천" 설정

### 1.4 클랜 테크 레이스 (주간)
- 여러 서버 클랜이 한 그룹에서 **주간 물약 기부량 경쟁**
- 순위별 보상(물약), **탈락 구역** 존재 → 리그 승강제
- 메인 화면 좌측 상단에 레이스 종료 타이머 아이콘

### 1.5 메인 화면 구성
- 상단: 프로필·전투력 / 코인·보석, 스테이지 "난이도 챕터-스테이지" + 3노드 진행바
- 좌우 아이콘: 테크 레이스 타이머, 요정(시즌 타이머), 진행 패스
- 전투: 플레이어 + 펫 + 요정, 스킬 버튼 3 + 자동 토글, 데미지 숫자
- 하단: 장비 8칸 + 탈것 칸(별·레벨·스킨 아이콘), **모루(망치 수)**, 대장간 레벨 버튼(업그레이드 남은 시간), 자동 버튼
- 채팅 한 줄 티커, 하단 탭 5개: 전투 / 던전 / 성장(스킬·펫·기술 트리) / 클랜 / 상점

### 1.6 요정 (시즌 동반자)
- 시즌 한정 동반자. 3종 중 선택, **언제든 교체 가능 + 업그레이드는 유지**, 최대 Lv20
- 각 요정은 고유 패시브 1개(예: N번째 공격 추가 피해 / 장착 체력 비례 피해 / 쿨감 비례 받는 치명 피해 감소)
- **시즌 종료 시 요정과 업그레이드 소멸**

### 1.7 진행 패스
- 스테이지 클리어 마일스톤마다 보상, 무료/프리미엄 2줄

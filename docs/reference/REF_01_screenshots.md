# 레퍼런스 분석 #01 — 스크린샷 20장 (프로필·랭킹·업적·상점·클랜·클랜전·임무·탈것 소환)

> 이 문서는 **관찰 기록**이다. 여기 적힌 수치·명칭은 원작의 것이므로 **우리 게임에 그대로 쓰지 않는다** (🟠/🔴 표시 참고).
> 스크린샷 원본은 다른 유저 닉네임이 포함되어 있어 저장소에 올리지 않는다.

## 1. 관찰된 시스템 요약

### 1.1 계정·서버·소셜
- **서버 분리 구조** (서버 번호 존재). 서버 시간 표시.
- 파워 랭킹(개인)·클랜 파워 랭킹: 서버 단위, **1시간마다 갱신**
- 프로필: 닉네임, 성별, 프로필 아이콘(초상화 선택), **리그 엠블렘(로마숫자 단계)**
- 전체 채팅 + 클랜 채팅 (설정에 채팅 표시/다크모드/클랜 채팅 미리보기, 차단 목록)
- 설정: 진동, 음악, 효과음, 언어, 계정 연동, 개인정보 보호

### 1.2 캐릭터 상세 (타인 정보 보기)
- 장비 **8슬롯 + 탈것 1슬롯**. 각 장비에 **아이템 레벨(100 이상까지)** + **별 3개 등급 표시**
- **장비 위에 코스튬(스킨) 아이콘이 따로 붙음** → 원작에도 외형 스킨 개념이 있음 (우리는 이걸 메인 BM으로 확장)
- 스킬 3칸 + 펫 3칸 + 별도 동반 캐릭터(레벨 표시)
- 대장간 레벨 + 별(★) — 대장간 레벨에도 단계 표시
- 총 피해 / 총 체력 / 전투력(대형 단위: k, m, b, t, q)
- 부가 스탯 종류: 치명타 확률, 치명타 피해, 생명력 흡수, **더블 찬스(추가 타격)**, 피해 %, **근접 피해 / 원거리 피해 분리**
- 스테이지 표기 "난이도 + 챕터-스테이지" (예: 어려움 10-3), 스테이지 내 진행 노드 3개

### 1.3 업적
- 달성률(%) 표시, 보상은 보석 소량
- 업적 종류에서 확인된 시스템: 클랜 미션 참여/실패, **승천(12회) = 환생/프레스티지 시스템 존재**, 같은 클랜 유지 일수, 클랜 기술 재화 수집, 스킬 레벨 100, 클랜 레이스류

### 1.4 상점
- 보석 상품 4종 (구글플레이 가격대 사용)
- **오늘의 특가**: 3개 패키지(탈것/스킬/자원 묶음), **3개 모두 구매하면 새 3개 등장**
- 확인된 재화: 코인(골드), 보석, 망치, 스킬 티켓, 물약(연구용 추정), 탈것 열쇠, 펫 알, 클랜 기술 물약

### 1.5 클랜
- 정원 50명, 클랜 등급(S/S+/S++ 형태), 총 전력, **클랜 기술(%) 버프**
- 직급: 리더 / 지휘관 / 대장 / R1~R5, 직급별 권한(승진·강등, 공지, 간부 채팅, 가입 승인, 추방, 클랜 기술 추천)
- 가입 방식 설정(승인제 등), 가입 요청 승인/거절, 공지사항
- 하단 탭: 회원 / 임무 / (잠김) / 전쟁

### 1.6 클랜 임무 + 랠리
- **에너지 3/일**, 매일 고정 시각 충전, **성공 시에만 에너지 소모**
- 임무마다 레벨·권장 전투력·보상(물약, 티켓, 열쇠, 알 등)
- **랠리**: 누군가 임무를 완료하면 **클랜원 전원이 소량 보상(망치)을 수집** → 협동 유도

### 1.7 클랜전 ("전쟁") — ⚠️ 기존 우리 설계와 다름
- **전투형이 아니라 "활동 점수 경쟁형"** (일주일 6일 진행, 다른 서버 클랜과 매칭)
- 매일 **점수가 붙는 행동 목록**이 다름. 확인된 행동: 대장간에 코인/보석 사용, 기술 트리 업그레이드 완료(티어별 차등), 탈것 소환(등급별), 던전 키 사용
- **일차별 승리 포인트가 다름** (후반 일차가 더 큼) → 마지막 날 역전 가능
- 일차별 승자 + MVP 표시, 주간 결과 = 승리 포인트 합
- **클랜 등급별 보상표** + 누적 포인트 마일스톤 보상 (진행 중에도 예상 보상 표시)

### 1.8 탈것 소환
- 등급 6단계: 일반 / 희귀 / 서사 / 전설 / 궁극 / 신화
- **소환 레벨**: 소환 횟수로 레벨이 오르고 레벨이 높을수록 상위 등급 확률 상승 (최대 레벨 100에서 확률표 확인됨)
- 등급 내 개별 탈것 확률까지 공시

## 3. ⚠️ IP 경고 (이번 분석에서 발견)
| 등급 | 항목 | 처리 |
|---|---|---|
| 🔴 | 원작 던전명(망치 도둑, 유령 마을, 침략, 좀비 러시), 임무명(헬름 군단, 별의 검 등) | 사용 금지 — 우리 던전명은 이미 자체 명칭 |
| 🟠 | 클랜전 행동별 점수값, 일차별 승리 포인트 배분, 탈것 확률(레벨 100 기준 표) | 숫자 복제 금지 — GDD에 자체 수치로 작성함 |
| 🟠 | 보석 수량 구성(60/220/800/3.3k) | 수량은 자체 설정. **가격대(₩2,800 등)는 구글플레이 표준 가격대라 무관** |
| 🟠 | 직급 명칭 "R1~R5 + 리더/지휘관/대장" | 다른 게임들도 쓰는 관습이지만, 판타지 테마에 맞춰 자체 명칭 사용 권장 → GDD에 제안 |
| 🟠 | 클랜 등급 "S/S+/S++" | 일반적 표기라 위험 낮음. 그래도 테마 명칭(보석 등급) 제안 |
| 🟢 | 클랜전 형식(활동 점수 경쟁), 랠리, 소환 레벨, 승천 | 시스템 구조이므로 참고 가능 |
